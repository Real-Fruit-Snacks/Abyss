Features

Deep extraction.

Credentials & Keys

Extract SAM hashes, NTDS.dit domain dumps, LSA secrets, DPAPI keys, browser passwords, SSH keys, and cloud credentials.

Disk & Memory Images

Supports Raw sector dumps, E01 (EnCase), and VMDK (VMware) with auto-detection. Parses LSASS minidumps for plaintext and NTLM extraction.

Native Rust Pipeline

High-performance, memory-safe parsing with a 13-crate workspace architecture and zero external tool dependencies.

Workflow

End-to-end extraction.

1

Provide Evidence

Point Abyss at a forensic disk image (Raw, E01, VMDK) or memory dump. It automatically detects the format and parses the filesystem.

2

Automated Analysis

The framework systematically locates and decrypts target artifacts, including SAM hives, NTDS.dit, DPAPI keys, and LSASS minidumps.

3

Actionable Output

Results are output in colored text, JSON, or Hashcat-ready formats for immediate password cracking workflows.

Get Started

Compile the framework.

Build from source

  1. Requires Rust toolchain (1.70+).
  2. Clone repository: git clone https://github.com/Real-Fruit-Snacks/Abyss.git && cd Abyss
  3. Build release: cargo build --release
  4. Analyze an image: ./target/release/abyss image disk.img --output hashcat
