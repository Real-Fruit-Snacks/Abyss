01 Premise

Dive into the depths of forensic evidence to extract hidden secrets.

Abyss is a Rust-built forensic analysis framework that extracts credentials, keys, and persistence mechanisms from disk images and memory dumps. Native parsers handle the entire pipeline from container formats to credential decryption.

Extract actionable intelligence from SAM hives, NTDS.dit databases, DPAPI secrets, browser passwords, SSH keys, and LSASS memory dumps — without external tool dependencies.

02 Specs

What's in the box.

EXTRACTION
SAM hashes · NTDS.dit · LSA secrets · DPAPI keys with native decryption support
BROWSERS
Chromium via DPAPI · Firefox via key4.db for saved password extraction

03 Quickstart

Clone, build, analyze, extract.

Abyss handles disk images, memory dumps, and interactive forensic analysis with native Rust parsers.

# Prerequisites: Rust 1.70+
$ git clone https://github.com/Real-Fruit-Snacks/Abyss.git
$ cd Abyss && cargo build --release

# Full disk image analysis
$ abyss image disk.img

# Memory dump analysis
$ abyss memory lsass.dmp

# Credentials extraction with Hashcat output
$ abyss image evidence.E01 --creds --output hashcat
04 Reference

Analysis modes and artifact extraction.

Complete command reference for disk image analysis, memory dumps, and credential extraction workflows.

DISK IMAGE ANALYSIS

abyss image <path>Full analysis of disk image
--credsExtract credentials only
--keysExtract SSH and cloud keys
--persistFind persistence mechanisms

MEMORY ANALYSIS

abyss memory <dump>Analyze LSASS memory dump
--packages msv1_0,wdigestSpecific credential packages

FILTERING & OUTPUT

--filter <types>Artifact types: sam_hash,ntds_hash,dpapi_key,browser_credential
--output <format>Output format: text, json, hashcat
--format hashcatHashcat modes 1000, 2100, shadow auto-detect

INTERACTIVE SHELL

abyss shell <image>Interactive filesystem browser
ls, cd, cat, hexdumpFilesystem navigation commands
hash, extractFile analysis and extraction

SUPPORTED FORMATS

*.img, *.rawRaw sector dumps
*.E01EnCase evidence format
*.vmdkVMware disk images
05 Architecture

Pipeline-driven, thirteen crates.

Modular architecture: Container parsers handle disk formats, volume parsers extract partitions, filesystem parsers navigate NTFS/ext4, extractors find artifacts, crypto modules decrypt credentials.

crates/
abyss-cli/        // command-line interface
abyss-container/  // Raw · E01 · VMDK parsing
abyss-volume/     // MBR · GPT partition tables
abyss-ntfs/       // NTFS filesystem parser
abyss-extfs/      // ext2/3/4 filesystem parser
abyss-registry/   // Windows registry hives
abyss-ese/        // ESE/JET database (NTDS.dit)
abyss-crypto/     // credential decryption
abyss-memory/     // LSASS memory analysis
06 Authorization

Authorized forensics only.

Abyss is designed for legitimate forensic analysis and incident response with proper authorization. Use only on disk images and memory dumps you own or have explicit permission to analyze.

Security vulnerabilities should be reported through private security advisories with 90-day responsible disclosure.

Read-only analysis — Abyss never modifies source disk images or memory dumps.
