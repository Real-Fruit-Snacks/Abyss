# Security Policy

## Reporting a Vulnerability

Report vulnerabilities via [GitHub Security Advisories](https://github.com/Real-Fruit-Snacks/Abyss/security/advisories).

**Do not open a public issue for security vulnerabilities.**

### Response Timeline
- **Acknowledgment**: Within 48 hours
- **Assessment**: Within 7 days
- **Disclosure**: 90-day coordinated disclosure

## Scope
- Parser vulnerabilities (malformed disk images, registry hives, ESE databases)
- Memory safety issues in credential extraction
- Information disclosure through error messages
- Path traversal in interactive shell
